## Tips for Recording Demo GIF or Screenshots
1. Ensure the browser is zoomed to 100%.
2. Toggle between Light and Dark mode using the top-right header switch to demonstrate theme fidelity.
3. Save images in PNG or WebP format for optimal contrast and sharpness.
